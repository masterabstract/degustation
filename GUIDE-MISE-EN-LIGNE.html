Mettre le site en ligne

Guide pas à pas pour Windows, sans aucune connaissance en programmation. Comptez 30 à 45 minutes la première fois.

Avant de commencer

Vous allez créer trois comptes gratuits, puis relier les trois services entre eux :

  • Supabase : la base de données, où sont rangées les bouteilles, les fiches et les pronostics.
  • GitHub : un « casier » en ligne qui contient les fichiers du site.
  • Vercel : l’hébergeur, qui lit les fichiers sur GitHub et met le site en ligne à une adresse du type votre-site.vercel.app.

Il vous faut un ordinateur Windows avec Chrome ou Edge, et une adresse e-mail. Rien à installer.

Ouvrez le Bloc-notes (touche Windows, tapez Bloc-notes, Entrée) et gardez-le ouvert : vous allez y noter quatre ou cinq informations au fil du guide.
Mot de passe base Supabase : SUPABASE_URL : SUPABASE_SECRET_KEY : ORGANIZER_PASSWORD : ANTHROPIC_API_KEY (facultatif) :

Les sites Supabase, GitHub et Vercel sont en anglais. Les noms de boutons sont indiqués comme ceci. Ils peuvent légèrement changer avec le temps : cherchez le bouton le plus proche.

Les étapes
  1. Décompresser le projet
  2. Créer la base de données
  3. Déposer les fichiers sur GitHub
  4. Mettre en ligne avec Vercel
  5. Vérifier et faire une répétition
  6. Le jour de la soirée
  7. Sauvegardes
  8. En cas de problème

1Décompresser le projet

2 minutes

  1. Repérez le fichier degustation-aveugle.zip téléchargé (en général dans Téléchargements).
  2. Faites un clic droit dessus, puis Extraire tout…, puis Extraire.
  3. Un dossier degustation-aveugle s’ouvre. Il contient notamment les dossiers app, components, lib, supabase et le fichier package.json.
Si en ouvrant le dossier vous voyez un seul sous-dossier degustation-aveugle, entrez dedans : c’est ce niveau-là (celui qui contient package.json) qui compte pour la suite.

2Créer la base de données Supabase

10 minutes

2.1 Créer le compte et le projet

  1. Allez sur supabase.com et cliquez sur Start your project.
  2. Créez un compte (le plus simple : avec votre e-mail, ou avec GitHub si vous créez GitHub d’abord). Validez l’e-mail de confirmation si on vous le demande.
  3. Si on vous demande de créer une « organisation », donnez-lui votre prénom et choisissez le plan Free.
  4. Cliquez sur New project et remplissez :
    • Project name : degustation
    • Database Password : cliquez sur Generate a password, puis copiez-le dans votre Bloc-notes. Vous n’en aurez normalement plus besoin, mais gardez-le.
    • Region : choisissez West EU (Paris) ou, à défaut, une région européenne.
  5. Cliquez sur Create new project et patientez 1 à 2 minutes : le projet se prépare.

2.2 Créer les tables avec le script fourni

  1. Dans votre dossier, ouvrez supabase, faites un clic droit sur schema.sql, puis Ouvrir avec > Bloc-notes.
  2. Dans ce Bloc-notes, sélectionnez tout avec Ctrl + A, puis copiez avec Ctrl + C.
  3. Dans Supabase, dans le menu de gauche, cliquez sur SQL Editor (icône >_).
  4. Cliquez dans la grande zone de texte (créez une requête avec New query si besoin), puis collez avec Ctrl + V.
  5. Cliquez sur Run en bas à droite (ou Ctrl + Entrée).
  6. Le message Success. No rows returned doit s’afficher. Si Supabase affiche un avertissement du type « destructive operation », confirmez : le script ne supprime aucune donnée.
Vérification : dans le menu de gauche, ouvrez Table Editor. Vous devez voir 5 tables : bottles, participants, predictions, ratings, tastings.

2.3 Récupérer l’adresse et la clé secrète

  1. L’adresse du projet (SUPABASE_URL). Regardez la barre d’adresse de votre navigateur : elle ressemble à supabase.com/dashboard/project/abcdefghijkl. Ces 20 lettres environ sont l’identifiant du projet. Votre adresse est donc :
    https://abcdefghijkl.supabase.co
    Notez-la dans le Bloc-notes. (Elle apparaît aussi dans Project Settings > Data API, ou via le bouton Connect en haut de la page du projet.)
  2. La clé secrète (SUPABASE_SECRET_KEY). Cliquez sur la roue dentée Project Settings en bas du menu de gauche, puis sur API Keys.
  3. Dans la partie Secret keys, une clé commençant par sb_secret_ est affichée de façon masquée. Cliquez sur l’icône pour l’afficher ou la copier, et collez-la dans le Bloc-notes. Si aucune clé secrète n’existe, cliquez sur Add new secret key.
Ne partagez jamais cette clé secrète (ni par message, ni en capture d’écran). Elle donne un accès complet à la base. Elle ne sera saisie qu’à un seul endroit : dans Vercel, à l’étape 4.
Si vous ne trouvez que d’anciennes clés nommées anon et service_role (onglet « Legacy API keys »), c’est la clé service_role qu’il faut utiliser, jamais la clé anon.

2.4 Choisir le mot de passe organisateur

Inventez un mot de passe simple à taper sur téléphone, par exemple Chambertin2026, et notez-le dans le Bloc-notes à la ligne ORGANIZER_PASSWORD. Il vous sera demandé pour créer une soirée, et empêche des inconnus d’en créer sur votre site.

3Déposer les fichiers sur GitHub

10 minutes, sans installer Git

  1. Allez sur github.com/signup et créez un compte gratuit (e-mail, mot de passe, nom d’utilisateur, puis le code reçu par e-mail).
  2. Une fois connecté, cliquez sur le + en haut à droite, puis New repository.
  3. Remplissez :
    • Repository name : degustation-aveugle
    • Cochez Private (privé).
    • Ne cochez rien d’autre (pas de README, pas de .gitignore, pas de licence).
  4. Cliquez sur Create repository.
  5. Sur la page qui s’affiche, repérez la phrase « …or create a new file or uploading an existing file » et cliquez sur le lien uploading an existing file.
  6. Ouvrez votre dossier degustation-aveugle dans l’Explorateur Windows (celui qui contient package.json). Sélectionnez tout son contenu avec Ctrl + A.
  7. Faites glisser cette sélection dans la zone « Drag files here » de la page GitHub. Attendez que la liste des fichiers apparaisse (une trentaine de fichiers, avec leurs dossiers).
  8. En bas de la page, cliquez sur le bouton vert Commit changes.
Vérification : la page de votre dépôt affiche les dossiers app, components, lib, supabase et les fichiers package.json, next.config.mjs… directement à la racine, pas à l’intérieur d’un dossier degustation-aveugle.
Si vous voyez un unique dossier degustation-aveugle à la racine, vous avez glissé le dossier au lieu de son contenu. Le plus simple : supprimez le dépôt (Settings, tout en bas Delete this repository) et recommencez cette étape.

4Mettre en ligne avec Vercel

5 à 10 minutes

  1. Allez sur vercel.com/signup. Choisissez Hobby (gratuit, usage personnel), donnez votre nom, puis Continue with GitHub et autorisez l’accès.
  2. Sur le tableau de bord, cliquez sur Add New… > Project.
  3. Dans « Import Git Repository », votre dépôt degustation-aveugle doit apparaître. S’il n’apparaît pas, cliquez sur Adjust GitHub App Permissions (ou Install), autorisez l’accès au dépôt, puis revenez.
  4. Cliquez sur Import à côté du dépôt.
  5. Sur la page de configuration, ne changez rien au « Framework Preset » (Vercel reconnaît Next.js tout seul). Dépliez la partie Environment Variables.
  6. Ajoutez les trois variables, une par une. Pour chacune : tapez le nom dans Key, collez la valeur depuis votre Bloc-notes dans Value, puis Add.
    Key (nom exact)Value
    SUPABASE_URLl’adresse https://….supabase.co
    SUPABASE_SECRET_KEYla clé sb_secret_…
    ORGANIZER_PASSWORDvotre mot de passe organisateur
    ANTHROPIC_API_KEY (facultatif)la clé de l’IA pour lire les étiquettes en photo (voir l’encadré « Lecture des étiquettes par photo » ci-dessous)
    Attention aux espaces en trop au début ou à la fin des valeurs collées.
  7. Cliquez sur Deploy. Vercel construit le site pendant 1 à 2 minutes.
  8. Quand des confettis et « Congratulations » s’affichent, cliquez sur Continue to Dashboard. L’adresse de votre site est indiquée sous Domains, du type degustation-aveugle.vercel.app (parfois avec quelques lettres en plus). Notez-la.
Vous pouvez changer cette adresse : Settings > Domains, puis modifiez le nom en …vercel.app (par exemple soiree-vin-mec.vercel.app), s’il est libre.
Si vous modifiez une variable plus tard (onglet Settings > Environment Variables), il faut relancer le site : onglet Deployments, les trois petits points du dernier déploiement, Redeploy.

Lecture des étiquettes par photo (facultatif)

Avec cette option, un bouton Photographier l’étiquette apparaît quand un invité ajoute sa bouteille. L’IA Claude lit la photo et remplit le formulaire. L’invité vérifie, corrige, puis enregistre. La photo n’est pas conservée, et le résultat n’est envoyé qu’au téléphone qui l’a prise.

Sans cette option, tout fonctionne aussi : le bouton est simplement absent et la saisie se fait à la main.

Obtenir la clé

  1. Allez sur platform.claude.com (la Claude Console) et créez un compte.
  2. Dans la partie Billing (facturation), ajoutez un petit crédit. Une photo coûte moins d’un centime : quelques euros suffisent pour de nombreuses soirées.
  3. Dans API Keys, cliquez sur Create Key, nommez-la degustation, puis copiez la clé (elle commence par sk-ant-). Elle ne s’affiche qu’une fois : collez-la tout de suite dans votre Bloc-notes.
  4. Dans Vercel, ajoutez la variable ANTHROPIC_API_KEY avec cette clé (Settings > Environment Variables), puis Redeploy.
Comme la clé Supabase, cette clé est secrète : elle ne doit être saisie que dans Vercel.
Conseils pour la photo : étiquette de face, bien éclairée, qui remplit l’écran. Vérifiez toujours le résultat avant d’enregistrer.

5Vérifier, puis faire une répétition générale

10 minutes, à faire avant le jour J

5.1 Le contrôle automatique

  1. Ouvrez dans votre navigateur l’adresse de votre site suivie de /api/sante, par exemple :
    https://degustation-aveugle.vercel.app/api/sante
  2. Vous devez lire : "ok":true et « Tout fonctionne : base de données connectée et configuration complète. »
  3. Sinon, le message indique ce qui manque : reportez-vous à l’étape 8.

5.2 Une mini-soirée de test (avec 2 téléphones)

  1. Sur votre téléphone, ouvrez l’adresse du site, puis Créer une dégustation. Nommez-la « Test », ajoutez deux prénoms, tapez le mot de passe organisateur.
  2. Copiez le lien organisateur qui s’affiche et envoyez-le vous par e-mail. Puis Ouvrir l’espace organisateur.
  3. Sur un 2e téléphone (ou en navigation privée), allez sur le site, tapez le code à 5 caractères et choisissez un prénom. Dans Mes bouteilles, ajoutez une bouteille (essayez la photo si vous l’avez activée).
  4. Sur le téléphone organisateur, onglet Bouteilles : la bouteille est comptée, sans aucun détail. Onglet Soirée : Lancer la dégustation. Ajoutez ensuite une 2e bouteille depuis le 2e téléphone : elle reçoit tout de suite le numéro suivant.
  5. Sur le 2e téléphone, le vin apparaît : remplissez les pronostics et la fiche, « Enregistré » s’affiche en bas. Sur le téléphone organisateur, l’onglet Suivi se met à jour en quelques secondes.
  6. Onglet Soirée : servez le n°1, puis onglet Révélation : Révéler le vin en cours (n°1) et confirmez. Sur le 2e téléphone, « Vin n°1 révélé » apparaît tout seul. Quand tous les vins sont révélés : Afficher les classements et le podium.
Si ces 6 points fonctionnent, le site est prêt pour la soirée. Vous pouvez laisser la soirée « Test » : elle n’apparaît nulle part ailleurs.

6Le jour de la soirée

Le principe : chaque invité enregistre lui-même ses bouteilles sur son téléphone. Personne d’autre ne les voit avant la révélation, pas même vous.

Avant l’arrivée des invités

  1. Créez la vraie soirée et ajoutez les 9 participants. Gardez le lien organisateur (e-mail à vous-même).
  2. Pour inviter : onglet Soirée, montrez le QR code (bouton Afficher en grand) ; chacun le scanne avec l’appareil photo de son téléphone. Vous pouvez aussi envoyer le lien direct (Copier le lien à partager) ou donner le code à 5 caractères. Les invités peuvent enregistrer leurs bouteilles dès maintenant, depuis chez eux, ou en arrivant.

Les bouteilles

  1. Chaque invité ouvre le lien, touche son prénom, puis Ajouter ma bouteille. Il choisit d’abord le pays (obligatoire : il décide du barème, 20 points pour un vin français, 23 pour un vin étranger), puis renseigne : domaine (obligatoire), appellation, cépages avec leurs pourcentages (obligatoire ; pour un assemblage, le total doit faire 100 %, ou laissez les % vides pour des parts égales), région, couleur, cuvée, millésime (obligatoire, ou « Non millésimé ») et un petit mot. Pour un vin étranger, deux champs de plus apparaissent : sous-région ou vallée, et grande zone (plus large que la région). Le site refuse une appellation ou une région qui appartient à un autre pays que celui choisi (ex. « Bourgogne » pour un vin italien). Ces réponses sont les bonnes réponses du concours : dès qu’un participant a noté ou deviné la bouteille, elles ne peuvent plus être modifiées.
  2. Saisie assistée : le site connaît plus de 1 000 appellations (toutes les appellations françaises, dont chaque grand cru d’Alsace et de Bourgogne, les IGP comme Pays d’Oc ou Côtes Catalanes, et Vin de France pour les vins nature sans appellation, et les appellations européennes : Italie, Espagne, Portugal, Allemagne, Autriche, Suisse, Grèce, Hongrie et les autres pays d’Europe, plus les grands vignobles du monde), 150 régions et 546 cépages. Couleurs possibles : effervescent, blanc, orange (vin de macération), rosé, rouge, doux. Une fois le pays choisi, les listes ne proposent que ce pays : avec Italie, la région propose Piémont, Toscane… et les cépages Nebbiolo, Sangiovese… (pas de Gamay). En touchant un champ vide, la liste complète s’ouvre ; en tapant les premières lettres (« gev »), le site propose « Gevrey-Chambertin ». En touchant une appellation, la région, le cépage et la couleur se remplissent tout seuls, et restent modifiables. Les accents ne sont pas nécessaires : « cote rot » trouve « Côte-Rôtie ».
  3. Pronostics, dans l’ordre (la page d’un vin s’ouvre sur l’onglet Pronostics, la fiche de dégustation est le deuxième onglet) : 1. le pays ; 2. la région, en touchant la carte des régions viticoles du pays (les zones colorées sont les aires officielles des appellations, regroupées selon les régions viticoles officielles de chaque pays : délimitation parcellaire de l’INAO pour la France, registre européen des AOP et organismes nationaux pour les autres pays) ou en tapant son nom ; 3. l’appellation, choisie parmi celles de la région (plus Vin de France) ; 4. les cépages, ceux de la région ; 5. le millésime. Si la bonne réponse n’est pas dans la liste de la région, il suffit de taper son nom : le site cherche alors dans tout le pays.
  4. Dans votre onglet Bouteilles, vous voyez seulement combien de bouteilles chacun a enregistrées. Un « Aucune » en rouge signale quelqu’un qui n’a pas encore saisi la sienne.
  5. Les numéros sont attribués au hasard automatiquement au lancement de la dégustation. Si vous voulez que chacun étiquette sa bouteille avant de commencer, cliquez sur Tirer les numéros au sort dès que les premières bouteilles sont enregistrées. Chaque invité lit alors sur son téléphone « Masquez la bouteille et écrivez dessus : n°7 ». Il masque sa bouteille (chaussette, papier aluminium), y écrit son numéro, et la pose avec les autres.
  6. Pas besoin d’attendre tout le monde : vous pouvez lancer la dégustation dès la première bouteille. Un invité qui arrive plus tard ajoute la sienne depuis son téléphone : elle reçoit aussitôt le numéro suivant, il voit le numéro à écrire dessus, et le vin apparaît chez tout le monde en quelques secondes. Les numéros déjà attribués ne changent jamais.

Pendant la dégustation

  1. Lancer la dégustation : les vins apparaissent sur tous les téléphones en quelques secondes, classés par numéro. On peut ajouter des bouteilles pendant toute la soirée, même après des révélations, jusqu’à l’affichage du podium. Un propriétaire peut retirer ou modifier la sienne tant que personne ne l’a notée ni devinée.
  2. Vous choisissez l’ordre de service en direct. Onglet Soirée, partie « Vin en cours de service » : touchez le numéro que vous servez. Sur tous les téléphones, ce vin passe en tête de liste avec la mention « En cours de service », suivi des vins déjà servis puis de ceux qui ne l’ont pas encore été. Un invité resté sur une autre fiche voit « On sert maintenant le n°4 » avec un bouton pour y aller.
  3. Chacun voit « votre bouteille » à côté de la sienne. Il peut la noter pour le plaisir, mais sa note et ses pronostics sur ce vin ne comptent pas.
  4. Suivez l’avancement dans l’onglet Suivi. Quelqu’un a changé de téléphone ? Onglet Participants, Libérer à côté de son nom : il pourra se reconnecter et retrouvera ses notes et ses bouteilles.

La révélation, vin par vin, pendant la dégustation

  1. Téléchargez d’abord une sauvegarde (onglet Soirée, Télécharger la sauvegarde).
  2. Quand tout le monde a goûté le vin en cours, onglet Révélation (ou Révéler un vin dans l’onglet Soirée) : touchez Révéler le vin en cours, ou le numéro d’un vin déjà servi, puis confirmez. Le site indique combien de fiches et de pronostics sont enregistrés sur ce vin. Seul ce vin est verrouillé : sa fiche et ses pronostics ne peuvent plus être modifiés.
  3. Sur chaque téléphone, l’annonce « Vin n°X révélé » apparaît toute seule, avec un bouton Voir la révélation. Après un compte à rebours, la bouteille apparaît avec son domaine, son appellation, sa note moyenne, son propriétaire, son petit mot, les pronostics et les points de chacun sur ce vin (avec le détail du calcul), et le classement provisoire en note sur 20. Vous pouvez aussi projeter l’écran de révélation sur une télévision.
  4. La dégustation continue : servez le vin suivant, et d’autres bouteilles peuvent encore être ajoutées après chaque révélation. Elles reçoivent un numéro et apparaissent sur tous les téléphones.
  5. Quand tous les vins sont révélés et qu’aucune bouteille ne doit plus arriver, touchez Afficher les classements et le podium et confirmez : le meilleur vin et le podium des dégustateurs s’affichent sur tous les téléphones, puis les classements complets, les commentaires et le résumé de la soirée. Ensuite, plus aucune bouteille ne peut être ajoutée.
  6. Après la révélation, vous voyez enfin les bouteilles dans l’onglet Bouteilles, et pouvez corriger une faute de frappe : les classements se recalculent. Téléchargez alors la sauvegarde finale, complète.
Barème du concours : la note d’un vin (sur 20) est la moyenne des notes des dégustateurs, sans celle de son propriétaire. Les pronostics sont notés sur 20 points pour un vin français et 23 pour un vin étranger :
  • Cépages (10 points) : monocépage exact 10 ; assemblage, chaque cépage trouvé rapporte sa part (70 % de Merlot = 7 points) ; moins 1 point par cépage cité à tort, sans descendre sous 0.
  • Pays : 2 points pour un vin français, 5 pour un vin étranger.
  • Géographie (5 points) : vin français, appellation exacte 5, sinon bonne région 3. Vin étranger, appellation ou indication exacte (DOCG, DOC, DO, AVA…) 5, sous-région ou vallée 4, grande région 3, grande zone (plus large que la région, ex. Italie du Nord) 2. Seul le meilleur niveau trouvé compte.
  • Millésime (3 points) : année exacte 3, puis on perd des points à chaque année d’écart : 1 point par an pour 2020 et après, 0,75 pour les années 2010, 0,6 pour 2000, 0,5 pour 1990, 0,3 pour 1980, 0,25 pour 1970, 0,2 pour 1960 et avant.
  • Classement : une note globale sur 20, au prorata du pourcentage des points possibles (71,5 % des points = 14,3/20), car personne ne joue sur ses propres bouteilles et chacun n’a donc pas le même nombre de points possibles. Départage : cépages, puis géographie, puis pays, puis millésime.
Accents, majuscules, tirets, mentions DOCG, AOC ou 1er cru, et synonymes courants (Shiraz et Syrah, Garnacha et Grenache…) sont ignorés. Le détail du calcul de chaque point est visible dans les résultats et dans la sauvegarde.
Dans les résultats, chacun voit le détail critère par critère (par exemple « Cépages 7/10, Géographie 3/5 »). Personne ne marque de points sur sa propre bouteille.

Archives et palmarès

  • Toutes les soirées restent enregistrées dans la base de données : rien n’est effacé après la révélation.
  • Sur la page d’accueil du site, Archives et palmarès affiche toutes les soirées révélées (avec le meilleur vin et le meilleur dégustateur), et un lien vers leurs résultats complets. Après la révélation, ces résultats sont consultables à tout moment, sans avoir à se reconnecter.
  • Effacer des soirées (ex : une soirée de test) : page Archives, onglet Soirées, touchez Effacer des soirées…, cochez les soirées, entrez le mot de passe organisateur (celui de la variable ORGANIZER_PASSWORD), puis confirmez. C’est définitif, et le palmarès se recalcule sans elles. Téléchargez la sauvegarde avant si vous voulez la garder.
  • L’onglet Palmarès classe tous les dégustateurs, toutes soirées confondues, selon leur note globale sur 20 sur l’ensemble de leurs soirées (pourcentage de tous leurs points possibles, ramené sur 20), avec leur nombre de soirées, de victoires et leur record. Chacun peut afficher le détail de ses soirées.
  • Une personne est reconnue d’une soirée à l’autre par son prénom (sans tenir compte des accents ni des majuscules) : demandez à chacun de garder toujours le même prénom ou pseudonyme.
  • Les soirées en préparation ou en cours n’apparaissent jamais dans les archives.
  • Pour effacer une soirée de test : espace organisateur, onglet Soirée, Supprimer cette soirée, puis recopiez son nom pour confirmer. Elle disparaît aussi des archives et du palmarès.
  • Les archives sont visibles par toute personne qui connaît l’adresse du site.

7Sauvegardes

Le plan gratuit de Supabase ne fait pas de sauvegarde automatique de la base. Le site vous permet d’en faire vous-même, en un clic :

  • Espace organisateur, onglet Soirée : Télécharger la sauvegarde. Un fichier .json contenant toute la soirée (participants, bouteilles, fiches, pronostics et, après la révélation, les résultats) est enregistré dans vos Téléchargements.
  • Faites-le au moins avant la première révélation et après le podium.
Un projet Supabase gratuit se met en veille après une semaine sans activité. Il suffit alors d’ouvrir le projet sur supabase.com et de cliquer sur Restore project : les données sont conservées. Pour garder vos archives des années, ne laissez pas le projet en veille trop longtemps (ouvrez le site de temps en temps) et téléchargez la sauvegarde finale de chaque soirée. Avant la soirée, aucun risque si vous faites la répétition dans la semaine.

Mettre à jour un site déjà en ligne

Quand je vous envoie une nouvelle version :

  1. Si l’archive contient des fichiers supabase/mise-a-jour-v2.sql, v3, v4… que vous n’avez pas encore lancés, lancez-les dans l’ordre : ouvrez chacun dans le Bloc-notes, copiez tout, collez-le dans Supabase > SQL Editor, puis Run.
  2. Décompressez la nouvelle archive. Sur GitHub, dans votre dépôt : Add file > Upload files.
  3. Sélectionnez tout le contenu du dossier décompressé (Ctrl + A) et faites-le glisser dans la page (pas le lien « choose your files », qui oublie les dossiers). Les anciens fichiers sont remplacés.
  4. Commit changes. Vercel reconstruit le site tout seul en 1 à 2 minutes.

8En cas de problème

Ce que vous voyezQue faire
Vercel affiche « Build Failed »Vérifiez sur GitHub que package.json est bien à la racine du dépôt (étape 3). Sinon, envoyez-moi le texte rouge du journal de construction.
/api/sante indique une variable manquanteAjoutez-la dans Vercel, Settings > Environment Variables, puis Redeploy.
/api/sante indique que la base ne répond pasVérifiez l’adresse (elle finit par .supabase.co, sans / à la fin), la clé (elle commence par sb_secret_), et que le script SQL a bien affiché « Success ». Puis Redeploy.
« Mot de passe organisateur incorrect »Comparez avec la valeur de ORGANIZER_PASSWORD dans Vercel (majuscules comprises).

Pourquoi personne ne peut tricher

  • Chaque bouteille n’est visible que par son propriétaire jusqu’à la révélation. L’organisateur ne voit que le nombre de bouteilles par personne et les numéros, jamais leur contenu ni qui a apporté quel numéro.
  • Les téléphones ne communiquent jamais directement avec la base de données. Ils passent par le serveur du site (Vercel), seul à connaître la clé secrète, et qui ne renvoie à chacun que ce qu’il a le droit de voir. Inspecter la page ou ses requêtes ne montre rien de plus.
  • La base Supabase est verrouillée : sécurité par ligne (RLS) activée sans aucune règle publique, et droits retirés aux accès publics. Même avec la clé publique du projet, une lecture directe est refusée.
  • Les numéros sont tirés au sort : ils ne correspondent pas à l’ordre de saisie.
  • Chaque prénom n’est utilisable que sur un seul téléphone à la fois. Un vin révélé est verrouillé : plus aucune fiche ni aucun pronostic ne peut être modifié sur ce vin.
  • La photo d’une étiquette part du téléphone vers le serveur du site, puis vers l’IA pour être lue. Elle n’est jamais enregistrée, et le résultat ne revient qu’à ce téléphone.

Seule limite théorique : l’organisateur pourrait « libérer » un invité puis se connecter sous son prénom pour voir ses bouteilles. L’invité serait alors immédiatement déconnecté sur son téléphone, donc il s’en apercevrait.
